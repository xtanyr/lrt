# Границы стейкхолдерского UAT

## Входит в тест

- вход по email и паролю для ролей лидер кофейни, лидер города, COO и администратор;
- заполнение, автосохранение, отправка и история отчёта;
- рейтинги за год, средние по городу и детализация кофейни;
- смена лидера с сохранением автора и истории отчётов;
- редактирование метрик, справочника кофеен и аудит изменений;
- preview и подтверждение исторического XLSX-импорта;
- desktop 1440×900 и mobile 390×844.

## Включается только при наличии тестовых интеграций

- Google OAuth требует отдельный Google OAuth client для UAT-домена;
- сброс пароля требует API key и подтверждённый адрес отправителя почтового сервиса.

Если credentials не переданы до dry run, эти два сценария исключаются из приглашения на UAT. Остальные функции работают независимо от них.

## Не входит

- запуск на производственном сервере и перенос производственных персональных данных;
- нагрузочное тестирование более чем с 20 одновременными пользователями;
- автоматический импорт из внешних систем — в v1 импорт выполняет администратор из XLSX;
- проверка почтовой доставляемости на корпоративные антиспам-фильтры.

UAT использует синтетические годовые данные. Реальный XLSX допускается только как заранее согласованный файл для одного контролируемого импорт-сценария и не включается в release-архив.
